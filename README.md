# Shubhamsingh Chaudhari — Full Stack Software Developer Portfolio

Static portfolio built with [Astro](https://astro.build). It ships plain HTML and CSS plus about 2 KB of vanilla JavaScript for the interactions (theme toggle, scroll-spy, skill and project filters, experience accordion, project dialogs). No UI framework runs in the browser.

## Run locally

```bash
npm install
npm run dev
```

Production build: `npm run build` (preview with `npm run preview`). The output in `dist/` can be hosted on any static host.

Content lives in `src/data/portfolio.js`; the resume is served from `public/resume.pdf`.
